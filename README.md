# Internshala Clone — Full Stack Job Portal

A full-stack **Internshala-inspired job portal** built using modern web technologies. This platform allows users to browse internships/jobs, apply for opportunities, manage authentication securely, and track application activity. It also includes recruiter/admin-side functionality and advanced authentication/device tracking features.

## 🚀 Live Demo

[Live Website](https://internshala-clone-iqya.vercel.app/?utm_source=chatgpt.com)

---

# 📌 Features

## 👤 User Features

* User authentication with JWT
* Login & Signup system
* OTP verification
* Forgot password functionality
* Apply for internships/jobs
* View application status
* Secure session handling
* Device/IP login tracking
* Responsive UI for mobile and desktop

## 🏢 Recruiter/Admin Features

* Post internships/jobs
* Manage applications
* View applicants
* Dashboard management
* Authentication-protected routes

## 🔒 Security Features

* JWT Authentication
* Protected API routes
* OTP-based verification
* Login history tracking
* Device detection
* IP address monitoring

# ⚙️ Installation

## 1️⃣ Clone the repository

```bash
git clone [https://github.com/Priyanka-Manapuram/internshalaClone.git]
```

## 2️⃣ Install dependencies

### Frontend

```bash
cd frontend
npm install
```

### Backend

```bash
cd backend
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
EMAIL=your_email
PASSWORD=your_email_password
```

---

# ▶️ Run the Project

## Start Backend

```bash
npm start
```

## Start Frontend

```bash
npm run dev
```
